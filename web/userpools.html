User Pools

Add your own pool or any pool that RainbowMiner does not ship. Every entry describes one stratum (one coin or algorithm at one region), all entries with the same name form one pool that takes part in the profit switching like the built-in pools. The wallet is stored in pools.config.txt under the pool name, exactly like for every other pool. The full field reference is in Doc/USERPOOLS.md.

General
Letters, digits and underscore only. All entries with the same name form one pool: the name is the section in pools.config.txt, the entry for PoolName and the name on the Pools page. Use the same name again for another coin, algorithm or region of the same pool.
