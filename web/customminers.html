Custom Miners

Add your own miner programs: RainbowMiner downloads the binary, benchmarks every algorithm you list and includes the miner in the profit switching. HiveOS flight sheets can be imported. The full field reference is in Doc/CUSTOMMINERS.md.

Name Enabled Devices API Algorithms Version Status Benchmarks Actions
New custom miner
General
Letters, digits and underscore only. Used for the Bin\Custom-<Name> folder, the miners.config.txt keys and the benchmark files.
Version of the binary. Changing it resets the benchmarks of this miner, changing only the URL downloads again and keeps them.
Download
Archive (zip, 7z) or a single executable. A single top level folder inside the archive is removed automatically.
Devices
How the selected devices are listed in %DEVICES%.
Hashrate and API
How RainbowMiner reads the hashrate. "Wrapper" parses the miner output for values like "12.3 MH/s", the other entries are the APIs of the built-in miners.
Base port, use $mport (or %MPORT%) in the arguments. Each miner needs its own base.
Optional. If set, the output lines are matched with this regular expression instead of the API selected above (named groups hashrate, unit, accepted, rejected; or group 1 = value, group 2 = unit).
Benchmark duration in multiples of BenchmarkInterval.
Command line
Placeholders: %ALGO% algorithm name of the entry, %URL% host:port, %HOST%, %PORT%, %PROTOCOL% (stratum+tcp / stratum+ssl), %WAL% or %USER% pool user (wallet.worker), %WALLET% plain wallet, %PASS%, %WORKER_NAME%, %COIN%, %ETHMODE%, %DEVICES% device list, %DEVCOUNT%, %THREADS%, %AFFINITY%, %AFFINITY_LIST% (CPU), $mport or %MPORT% API port. Unknown placeholders stay as they are.
Appended when the pool uses SSL.
Comma separated NAME=VALUE pairs.
Regular expression matched against the pool host.
Ignored on Windows when the hashrate is read from the output (Wrapper).
Algorithms
Algorithm Miner name Extra params Fee % Min GB DAG Extend Devices
Algorithm = RainbowMiner name (see the Algorithms page), Miner name = the name the binary expects for %ALGO% (defaults to the algorithm), Devices = optional subset of the device types above (e.g. NVIDIA,AMD).
