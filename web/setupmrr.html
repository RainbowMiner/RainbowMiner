Setup MRR

The MiningRigRentals section of pools.config.txt (tab "Pool settings") holds the settings for all rigs. They are refined per worker name in mrr.config.txt and per algorithm in mrralgorithms.config.txt. A field that is left empty is not set at this level. If a parameter is set at more than one level, the algorithm wins over the worker, and the worker over pools.config.txt. All parameters are described in Doc/MININGRIGRENTALS.md.

The MiningRigRentals parameters of pools.config.txt. They apply to every worker and algorithm that has no own value. The parameters that all pools share (Worker, Penalty, the algorithm, coin and miner filters) stay on the page Setup Pools.

The worker name of a rig: WorkerName of config.txt for the GPUs, the same name with cpu appended for the CPU, or the Worker of a device group in devices.config.txt. The names of this rig are listed automatically, add a name here only for another rig that receives this file.
