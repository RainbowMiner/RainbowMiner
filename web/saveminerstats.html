Clean up stale benchmarks

A rig keeps the benchmark of every miner, device set and algorithm it ever ran. The scan lists the benchmarks that no current miner can use and that have not been updated for the given number of days. The listed files are deleted from .\Stats\Miners, the current benchmarks are saved as a "before cleanup" backup first, so a cleanup can be undone.
